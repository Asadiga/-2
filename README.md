# بوت واتساب مثل Tab — دليل البدء

بوت واتساب بسيط للمساعد الشخصي: يرد بالعربية، يتذكر اسمك ومشاريعك وملاحظاتك في ملف محلي، و**بدون حد يومي للرسائل افتراضياً** (DAILY_LIMIT=0)، حتى لا يتوقف فجأة كما حصل مع Tab سابقاً. إن أردت حداً يومياً، يمكنك ضبطه من ملف `.env`.

## ما تحتاجه قبل التشغيل

1. **رقم واتساب للبوت:** يفضّل أن يكون رقماً منفصلاً عن رقم واتساب الشخصي، لأن البوت يستخدم واتساب ويب على ذلك الرقم. إذا استخدمت رقمك الشخصي، قد يتأثر استخدامك العادي لواتساب.
2. **Node.js 18 أو أحدث** على جهازك.
3. **مفتاح API للذكاء الاصطناعي** (اختياري في البداية): البوت يعمل بدونه بالأوامر والردود الاحتياطية، لكن الرد الذكي يحتاج مفتاحاً. لا تضع المفتاح في أي محادثة؛ ضعه في ملف `.env` فقط.

## التثبيت

```bash
cd tab-bot
npm install
cp .env.example .env
```

ثم افتح ملف `.env` في محرر نصوص وعدّل ما يلي إن أردت:

```env
AI_API_KEY=ضع_مفتاحك_هنا
AI_API_URL=رابط_واجهة_مزودك_إن_وجد
AI_MODEL=اسم_النموذج
BOT_NAME=مساعد
DAILY_LIMIT=0
```

ملاحظة: ملف `.env` غير موجود في هذا المشروع عمداً، وفيه مثال فقط (`.env.example`). لا يوجد أي مفتاح حقيقي مضمّن في الكود.

## التشغيل ومسح QR

```bash
npm start
```

1. ستظهر في الطرفية رمز QR.
2. افتح واتساب في الهاتف الذي يحمل **رقم البوت**، ثم: الأجهزة المرتبطة > ربط جهاز > امسح رمز QR.
3. بعد أول مسح ناجح تُحفظ الجلسة في مجلد `auth/`، فلن تحتاج لمسح QR في كل تشغيل، إلا إذا سجلت الخروج.
4. أرسل رسالة إلى رقم البوت من أي هاتف، وسيرد عليك.

## كيف تستخدمه؟ اكتب مباشرة، بلا أوامر

اكتب لأثير بالعربية كما تتحدث، وهو ينفذ مباشرة مثل Tab، بدون أي أوامر:

| اكتب له | ماذا يفعل |
|---|---|
| `افتح موقع east-sources.com` | يفتح الموقع في متصفحه الخاص ويلخصه لك |
| `ابحث عن أفضل شركات الاستيراد` | يبحث لك في الإنترنت |
| `احفظ مشروع فيلدورا \| مدينة حياة واقعية في روبلوكس` | يحفظ مشروعك |
| `مشاريعي` | يعرض مشاريعك المحفوظة |
| `احفظ ملاحظة راجع درس الجامعة غداً` | يحفظ ملاحظتك |
| `سجل موعد 2026-11-20 10:00 \| موعد طبيب` | يسجل موعدك |
| `مواعيدي` | يعرض مواعيدك |
| `سجل دخول بحسابي في يوتيوب` | يسجل دخول بأي حساب تعطيه إياه |
| `نزل فيديو في حسابي على يوتيوب` | ينشر بعد موافقتك |
| `صمم صورة مدينة مستقبلية` | يصمم لك صورة فوراً ويرسلها كصورة واتساب |
| `اعمل فيديو عن فيلدورا` | يشرح لك بصدق أن توليد الفيديو يحتاج مفتاحاً مدفوعاً، ويعرض بديل الصور |
| أي سؤال أو موضوع آخر | يرد عليك كمساعد ذكاء اصطناعي |

## أفضل الأدوات في أثير الآن

**متوفر الآن (مجاني):**
- اللغة الطبيعية مباشرة، بلا أوامر — اكتب ما تريده بالعربية.
- المتصفح الخاص (Playwright/Chromium): فتح المواقع والبحث في الإنترنت.
- المشاريع والملاحظات والمواعيد: حفظ وعرض باللغة الطبيعية.
- تصميم الصور: عبر Pollinations Image API المجاني، بلا مفتاح، وتُرسل كصورة واتساب.
- رد ذكاء اصطناعي مجاني (Pollinations) لأي موضوع، مع ردود محلية فورية للتحية والحساب والوقت.
- الرد على الصادق وحده، وتجاهل الأرقام الأخرى والمجموعات.
- بلا حد يومي للرسائل (DAILY_LIMIT=0).

**ما زال يحتاج مفتاحاً مدفوعاً أو خدمة مدفوعة:**
- توليد الفيديو: لا يوجد بديل مجاني موثوق؛ يحتاج مفتاح API لخدمة توليد فيديو مدفوعة.
- رد ذكاء اصطناعي سريع: الرد المجاني بطيء (14-21 ثانية)؛ السرعة تحتاج مفتاح API خاص بك.
- المكالمات الهاتفية: تحتاج خدمة اتصال مدفوعة.
- الدفع والشراء: يحتاج بطاقة ومحفظة موثقة، ولا يتم إلا بموافقتك على كل مبلغ.

## تسجيل الدخول بحسابك والنشر بعد موافقتك

اكتب لأثير مثلاً: `سجل دخول بحسابي في يوتيوب` أو `سجل دخول بهذا البريد asadig@example.com` أو `نزل فيديو في حسابي على انستقرام`.

- يعمل مع **أي حساب تعطيه إياه**: يوتيوب، انستقرام، تيك توك، فيسبوك، أو أي منصة أخرى، وأي بريد تعطيه إياه.
- **لا ترسل كلمة المرور في المحادثة أبداً**؛ أثير يطلب المنصة والبريد أو اسم المستخدم فقط، والحساب يُربط بطريقة آمنة، ويستخدم متصفحه الخاص وجلسة محفوظة إن وجدت.
- قبل أي نشر، يعرض لك أثير العنوان والمكان الذي سينشر فيه، **ولا ينشر شيئاً إلا بعد موافقتك**.
- هذا التصميم والكود فقط؛ لم يتم تسجيل الدخول إلى أي حساب فعلياً في هذا المشروع.

لا تحتاج لأي أمر يبدأ بـ `/`؛ الأوامر القديمة ما زالت تعمل كبدائل فقط، لكنها ليست مطلوبة أبداً.

## الذاكرة والحد اليومي

- الذاكرة محفوظة محلياً في `data/memory.json`: اسمك (الصادق)، مشاريعك، ملاحظاتك، وعداد الاستخدام اليومي. لا تُرسل لأي خادم.
- الحد اليومي الافتراضي **بلا حد (0 رسالة كحد، أي غير محدود)**، ويمكن تغييره من `DAILY_LIMIT` في `.env`. إن ضبطت حداً أكبر من صفر، فعند الوصول إليه يرد البوت برسالة واضحة بأن الحد وصل، ويعود للعمل في اليوم التالي، أو بعد رفع الحد وإعادة التشغيل.
- العداد يصفّر تلقائياً عند تغير اليوم.

## ملفات المشروع

- `package.json` — الاعتماديات وأمر التشغيل (`npm start`).
- `index.js` — الاتصال بواتساب عبر Baileys وعرض QR والرد على الرسائل.
- `bot.js` — منطق الردود باللغة الطبيعية مباشرة (بلا أوامر)، والحد اليومي ودالة الذكاء الاصطناعي القابلة للتبديل.
- `browser.js` — متصفح أثير الخاص (Playwright/Chromium) لفتح المواقع والبحث.
- `memory.js` — قراءة وحفظ الذاكرة المحلية والمشاريع والملاحظات.
- `.env.example` — مثال لإعدادات البيئة (بدون أي مفتاح حقيقي).
- `data/memory.json` — يُنشأ تلقائياً عند أول رسالة.

## تنبيهات مهمة

- هذا بوت تجريبي مبني على واتساب ويب (Baileys)، وليس واجهة واتساب للأعمال الرسمية. استخدام رقمك الشخصي للبوت قد يعرض حسابك لقيود من واتساب؛ لذلك يفضّل رقم منفصل.
- لا تشارك ملف `.env` أو مجلد `auth/` مع أحد؛ فيهما مفتاحك وجلسة واتساب.
- لم يتم تسجيل الدخول إلى واتساب أثناء بناء هذا المشروع، ولم يُدخل أي حساب أو مفتاح.
